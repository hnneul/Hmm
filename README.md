# Hmm

  AI 답변을 복사하는 순간, 사용자가 한 번 더 검증하도록 유도하는 넛지형 Chrome Extension 프로토타입입니다.

  ## 프로젝트 소개

  생성형 AI 답변은 빠르고 편리하지만, 사용자가 내용을 그대로 복사해 사용하면 사실 확인이나 비판적 검토 과정
  이 생략될 수 있습니다.

  Hmm은 AI 답변 복사 순간에 작은 펫 캐릭터가 개입해 사용자가 답변을 다시 확인하도록 유도합니다.

  ## 주요 기능

  - AI 답변 복사 상황 시뮬레이션
  - 넛지 강도 선택
  - 펫 캐릭터 상태 변화
  - 확인 / 무시 횟수 기록
  - 검증 사이드 패널 제공
  - 반대 관점, 누락된 맥락, 점검 질문 제시

  ## 실행 방법

  별도 설치 없이 `index.html` 파일을 브라우저에서 열면 실행됩니다.

  ## 사용 방법

  1. `AI 답변 복사 시뮬레이션` 버튼을 클릭합니다.
  2. 넛지 말풍선이 나타나면 `확인해볼게요` 또는 `그냥 할게요`를 선택합니다.
  3. `확인해볼게요`를 누르면 검증 패널이 열립니다.
