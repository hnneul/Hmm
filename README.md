# Hmm

생성형 AI를 무비판적으로 사용하는 순간에 자동 개입해, 대학생이 AI 답변을 한 번 더 검증하도록 돕는 React 기반 Chrome Extension 콘셉트 프로토타입입니다.

## 핵심 컨셉

Hmm은 AI가 판단을 대신하는 서비스가 아니라, 사용자가 스스로 생각하도록 질문을 던지는 AI 리터러시 안내자입니다. 전용 캐릭터가 브라우저 안에 펫처럼 존재하며 복붙, 단순 요약, 과제 제출 같은 사용 맥락을 감지해 짧은 넛지를 제공합니다.

## 반영된 시나리오

- 연속 복붙 감지: 장기간 세션과 반복 복붙이 누적되면 다른 관점 확인을 제안
- 논문 요약 검증: 논문을 3줄 요약하는 요청에서 초록 확인을 유도
- 제출 후 성장 리포트: 과제 제출 시 AI 활용 리포트와 리터러시 점수 표시
- 캐릭터 5단계 상태: 요청 수락률에 따라 긍정, 미소, 기본, 찡그림, 슬픔 상태 변화

## 실행 방법

React + Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

저장소 폴더에서 위 명령어를 실행한 뒤, 브라우저에서 터미널에 표시되는 로컬 주소를 열면 됩니다.
기본 주소는 `http://localhost:5173`입니다.
