# Hmm

생성형 AI를 무비판적으로 사용하는 순간에 자동 개입해, 대학생이 AI 답변을 한 번 더 검증하도록 돕는 React 기반 Chrome Extension 콘셉트 프로토타입입니다.

## 핵심 컨셉

Hmm은 AI가 판단을 대신하는 서비스가 아니라, 사용자가 스스로 생각하도록 질문을 던지는 AI 리터러시 안내자입니다. 전용 캐릭터가 브라우저 안에 펫처럼 존재하며 복붙, 단순 요약, 과제 제출 같은 사용 맥락을 감지해 짧은 넛지를 제공합니다.

## 시나리오

탭으로 전환하며 세 가지 시나리오를 체험할 수 있습니다.

### 1. 연속 복붙 감지

AI 답변 카드에서 텍스트를 복사한 뒤 과제 작성창에 붙여넣으면 복붙 횟수가 누적됩니다. **세션 50분 이상 + 복붙 3회 이상**이 되면 팝업이 자동으로 등장해 다른 관점 탐색을 제안합니다.

> 데모에서는 1 디스플레이 분 = 10초 실시간으로 가속되어 실행됩니다.

우측 패널의 실시간 감지 상태에서 세션 시간, 복붙 누적 횟수, 최근 이벤트, 감지 시각을 확인할 수 있습니다.

### 2. 논문 요약 검증

논문을 3줄 요약하는 요청 맥락을 보여주고, 팝업에서 초록 직접 확인을 유도합니다.

### 3. 제출 후 성장 리포트

학교 과제 제출 도메인 맥락에서 AI 활용 세션 리포트를 생성합니다. 복붙 시도·수정 횟수, 출처 확인 횟수, 리터러시 점수와 레벨을 표시합니다.

## 캐릭터 상태

Hmm 캐릭터는 **넛지 수락률**에 따라 5단계로 변화하며, 수락 시 +8점, 무시 시 −16점으로 점수가 변동됩니다.

| 단계 | 상태 | 수락률 기준 |
|------|------|------------|
| 1단계 | 극단 긍정 (별·하트 장식) | 90% 초과 |
| 2단계 | 활짝 웃는 표정 | 70% 초과 |
| 3단계 | 디폴트 (은은한 미소) | 40% 초과 |
| 4단계 | 찡그리고 화난 표정 | 20% 초과 |
| 5단계 | 극단 슬픔 (원형 프레임) | 20% 이하 |

우측 패널에서 현재 단계와 수락률 게이지를 실시간으로 확인할 수 있습니다.

## 실행 방법

React + Vite 프로젝트입니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다. 기본 주소는 `http://localhost:5173`입니다.

## 인터랙션 방법

- **시나리오 실행** 버튼: 현재 시나리오의 넛지 팝업을 즉시 표시
- **캐릭터 클릭**: 팝업 다시 열기
- **복붙 직접 테스트**: AI 답변 텍스트를 드래그해 복사 → 과제 작성창에 붙여넣기
- **수락 / 무시 버튼**: 캐릭터 상태와 수락률 변동 확인
